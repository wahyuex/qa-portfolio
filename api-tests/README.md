# API Testing & Postman Collection

Folder ini berisi dokumentasi pengujian REST API menggunakan Postman pada sistem RMA dan Manajemen Kavling.

## Endpoint yang Diuji:
1. `POST /api/v1/auth/login` (Positive & Negative Authentication Test)
2. `POST /api/v1/rma/tickets` (Create RMA Ticket Payload Validation)
3. `GET /api/v1/reports/profit` (Financial Report Calculation Verification)

*(File Postman Collection (.json) akan di-update secara berkala)*
